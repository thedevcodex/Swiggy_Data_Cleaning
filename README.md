# 🍔 Swiggy Data Cleaning

A beginner-friendly **Data Cleaning and Preprocessing** project using a messy Swiggy food-delivery dataset.

## 📌 About

This project focuses on cleaning real-world style data and preparing it for further **EDA and Machine Learning**.

### 🛠️ Technologies

* Python
* Pandas
* NumPy
* Google Colab

### 🧹 Cleaning Performed

* Handled missing values
* Removed duplicate records
* Standardized categorical values
* Cleaned date formats
* Cleaned currency values
* Converted data types
* Handled inconsistent text values
* Performed final data validation

### 📊 Dataset

* **Rows:** 512
* **Columns:** 26
* **Domain:** Food Delivery
